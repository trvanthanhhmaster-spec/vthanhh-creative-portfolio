# Vthanhh Creative Portfolio

A standalone creative portfolio for Trần Văn Thành (Vthanhh).

## Stack
- Next.js 15 / React 19 / TypeScript
- Three.js + React Three Fiber (isolated 3D scene)
- GSAP + ScrollTrigger + Lenis
- Web Audio API (opt-in ambient sound)

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run typecheck
```

## Deploy
Connect this repository to Vercel. Use `main` as the production branch. Preview deployments are intended for visual review before connecting a custom domain.

The 3D scene is procedural. A Blender-exported GLB can replace or extend the emblem later.
